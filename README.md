# pages

[耗电模式](docs/index.html)用于持续增加设备耗电，不提供性能评分。GitHub Pages 发布目录使用 "/docs"。

页面只保留左上角全屏图标、中央开始／停止按钮和运行数据卡片，无参数选择。

- CPU：按浏览器报告的并发数的两倍创建 Worker（最多 64 个），持续执行混合浮点与整数运算，不使用定时器让计算线程等待；父页面用 terminate() 结束线程。工作线程不会随帧率降低负载。增加线程数不等于硬件利用率翻倍，网页无法验证所有核心是否达到 100% 利用率。
- GPU：固定使用此前最高负载：16 MB 计算 buffer、512 次 compute 迭代、每批 4 次 dispatch、192 步 Raymarch、16 次分形迭代和完整渲染分辨率。取消帧率目标和自动降载。WebGPU 每批完成后立即提交下一批，不等待显示刷新；同时最多保留两批在途任务，预先填充队列，减少等全部工作结束后才提交造成的空档，避免无限积压。WebGL2 回退仅支持渲染负载，按显示刷新尽快绘制。网页无法验证实际 GPU 利用率或保证最大功耗。
- 屏幕：普通白色背景，已移除 HDR 画布、设备请求及独立刷新循环。
- 唤醒：开始时请求，停止、切换到后台、关闭或离开页面时释放；释放失败会重试，持续失败会显示错误；未完成的旧请求返回后也会释放。恢复页面不会自动启动耗电任务，不更改系统自动锁屏设置。

数据卡片仅展示运行时间、工作线程、GPU 计算缓冲区容量及 GPU 状态，不推算功耗或电池耗电百分比。

GPU 仅在开始时初始化，停止时销毁设备、解除画布配置并移除状态定时器；延迟完成的初始化也会清理。待机页面不保留 GPU 设备或定时刷新。

Safari 兼容标准及 WebKit 全屏接口、动态视口和横竖屏尺寸变化。GPU 异常时停止耗电任务，不自动重启。

根目录的原始 ipad-burn.html 保留为本地参考，不修改其内容。
