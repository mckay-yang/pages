# 耗电模式 v0.1.0

[打开页面](docs/index.html)。GitHub Pages 发布目录为 `/docs`。页面仅显示液态玻璃风格的开始／停止按钮和底部 `v0.1.0`，不提供性能评分或参数设置。

点击开始后，以下负载并行运行；取消帧率目标，不根据帧率自动降载。

| 负载 | 实际任务 | 能力边界 |
| --- | --- | --- |
| CPU 整数 | 独立 Worker 持续执行整数乘法、异或与移位混合运算 | JavaScript 执行单元分配由引擎决定 |
| CPU 浮点 | 独立 Worker 持续执行 sin、cos、sqrt 和浮点乘除 | 不保证特定浮点执行管线满载 |
| CPU 矩阵 | 独立 Worker 持续进行 128×128 矩阵点积，使用多个累加器 | 不等于直接调用 CPU 内部专用机器学习加速器 |
| 内存读写 | 独立 Worker 对两块各 8 MiB 的数组持续复制、跨步访问和写回 | 不是磁盘交换，不分配无限增长的内存 |
| GPU 计算／渲染 | 16 MiB 缓冲区、512 次计算迭代、每批 4 次 dispatch；192 步 Raymarch、16 次分形迭代，最多两批在途 | WebGPU 不可用时尝试 WebGL2，仅渲染；再不可用则跳过 GPU |
| 视频编解码 | 独立 Worker 本地生成动态 1080p 画面，用 H.264 编码再解码，及时关闭 VideoFrame，限制队列大小 | 检测 WebCodecs 支持；请求 prefer-hardware，但不能保证使用专用媒体引擎 |
| 加密 | 独立 Worker 对 4 MiB 数据持续执行 AES-256-GCM 与 SHA-256，每轮使用不同 IV | Web Crypto 是否使用专用硬件由浏览器决定，不代表 Secure Enclave 负载 |
| 神经网络 | WebNN 可用时持续执行 256×256 矩阵乘法与 ReLU，使用可销毁的图和张量 | 请求高性能硬件加速；具体使用 CPU、GPU 或 NPU 由浏览器选择，不能保证 Neural Engine 被调用 |

CPU 计算 Worker 数为浏览器报告并发数的两倍，最少 4、最多 64，轮流分配给整数、浮点、内存、矩阵任务；另外增加 1 个加密 Worker 和 1 个视频 Worker。不支持的可选 API 会跳过并在控制台诊断中注明，不伪装成已运行。

不使用摄像头或麦克风，因此不通过拍摄来调用 ISP。Secure Enclave、独立安全模块及存储控制器没有通用网页压测接口；本页面不宣称覆盖所有芯片单元。所有计算和视频数据仅在本机内存中处理，不保存或上传，不下载模型，不进行持续磁盘写入。已移除 HDR。

开始时请求屏幕唤醒锁。停止、切到后台或离开页面时终止全部 Worker、销毁 GPU/WebNN 资源并释放唤醒锁；延迟完成的初始化或唤醒请求也会清理。返回前台不会自动继续。待机不保留计算任务、GPU 设备或定时刷新，不改变系统自动锁屏设置。GPU 异常会停止任务，按钮显示“重试”，仅在用户再次点击后尝试恢复。

界面不展示运行统计；开发调试可在控制台读取 `window.burnDiagnostics`，检查各任务的 `running`、`unavailable`、`failed`、`stopped` 状态和进度。运行状态不等于硬件利用率测量，网页无法保证所有核心或整个芯片满载，也无法保证最快掉电。

参考：[WebCodecs 标准（硬件加速只是偏好）](https://www.w3.org/TR/webcodecs/)、[WebNN 标准（执行设备由浏览器选择）](https://www.w3.org/TR/webnn/)。
